# 0010 · P03 runs before P02

Date: 28 Nov 2026 · Decided by: Jann · Surfaced by: P03 refinement

## Decision

P03 (run runtime) is refined and built now, before P02 (store and state machines), while P01 is
refined in parallel. `CLAUDE.md`'s stage-1 order puts P02 and P03 together after P01; P03 depends
only on P00 (umbrella §9), so it can go first.

## Options considered

- Keep the order: P03 waits until P01 has merged.

## Consequences

- P03 and P01 both add workspace dependencies: the root `Cargo.toml` and `Cargo.lock` may need a
  merge of `main` before P03's PR. P03's plan says so.
- P03 is the first phase that uses PostgreSQL (decision 0017): it adds the store's first table,
  and P02 designs the rest of the store on top of it.
